# Локальная поисковая система «АйТиБокс»

Программа для быстрого поиска слов в текстовых файлах компании. Она умеет одновременно обрабатывать несколько документов и выдавать результаты в виде списка, где самые подходящие файлы находятся в самом верху.

Данный проект выполнен в качестве финальной дипломной работы курса **«С++ разработчик»**.

---

## Стек технологий
* **Язык программирования:** C++ 
* **Система сборки:** CMake 
* **Среда разработки:** Visual Studio Code 
* **Компилятор:** MinGW-w64 
* **Библиотека JSON:** nlohmann/json
* **Тестирование:** Google Test (GTest)


---

## Структура проекта
Проект организован по модульному принципу:
* `include/` — заголовочные файлы классов и внешние заголовочные библиотеки (`ConverterJSON.h`, `InvertedIndex.h`, `SearchServer.h`, `json.hpp`).
* `src/` — файлы реализации бизнес-логики (`ConverterJSON.cpp`, `InvertedIndex.cpp`, `SearchServer.cpp`).
* `tests/` — автоматизированные модульные тесты для проверки ядра системы (`tests.cpp`).
* `main.cpp` — точка входа.
* `CMakeLists.txt` — конфигурация сборки.

---

## Как работает программа

1. **Запуск и проверка (`ConverterJSON`):** Программа включает поисковый движок, находит файл настроек `config.json` и проверяет, что он не пустой и имеет правильную версию (`0.1`).
2. **Быстрое чтение файлов (`InvertedIndex`):** Компьютер одновременно запускает несколько потоков, чтобы мгновенно прочитать все текстовые документы. Программа переводит все буквы в нижний регистр, убирает точки с запятыми и считает, сколько раз каждое слово встречается в текстах.
3. **Поиск совпадений (`SearchServer`):** Движок забирает список запросов из файла `requests.json`, ищет нужные слова в базе данных и считает общую пользу каждого документа.
4. **Сортировка и выдача результатов:** Программа оценивает файлы по шкале от 0 до 1. Самые полезные документы с высшим баллом встают на первые места. Итоговый список (до 5 лучших совпадений) сохраняется в готовый файл `answers.json`.

## 🚀 Инструкция по локальному запуску

### Предварительные требования
Для успешной сборки в VSCode должны быть установлены:
1. Компилятор **MinGW-w64** (путь к папке `bin` должен быть добавлен в системную переменную `PATH`).
2. Расширения для VSCode: **C/C++** и **CMake Tools** .

### Шаг 1. Конфигурационные файлы
Перед запуском приложения убедитесь, что в папке запуска (по умолчанию папка `build`) лежат конфигурационные файлы в формате JSON.

**config.json**
```json
{
    "config": {
        "name": "ITBoxSearchEngine",
        "version": "0.1",
        "max_responses": 5
    },
    "files": [
        "file001.txt",
        "file002.txt"
    ]
}
```

**requests.json**
```json
{
    "requests": [
        "milk water",
        "sugar"
    ]
}
```

*(Текстовые файлы `file001.txt` и `file002.txt` должны быть созданы в этой же папке и содержать текст для индексации).*

### Шаг 2. Локальная сборка проекта

1. Откройте встроенный терминал в VSCode и перейдите в папку `build`:
   ```powershell
   cd build
   ```
2. Запустите генерацию файлов под стандартный MinGW:
   ```powershell
   cmake -G "MinGW Makefiles" ..
   ```
3. Скомпилируйте проект:
   ```powershell
   cmake --build .
   ```

#### Вариант Б. Прямая компиляция через g++ (Если на Windows конфликтует утилита Ninja)
Если встроенные плагины выдают ошибку Ninja, соберите проект напрямую через компилятор:
```powershell
cd build
C:/msys64/ucrt64/bin/g++.exe -std=c++17 -w -I../include ../main.cpp ../src/ConverterJSON.cpp ../src/InvertedIndex.cpp ../src/SearchServer.cpp -o search_engine.exe
```
